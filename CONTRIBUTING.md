# Contributing to Founders Kit

Thank you for wanting to improve this repository. This project is intended to be a growing, practical resource for founders and builders.

## How to contribute

- Add new resources to the appropriate section in `README.md`.
- Keep links relevant, high-quality, and non-spammy.
- For new categories or major sections, create a short description and keep formatting consistent.
- If you add tools, include the type of founder or stage it helps most.
- If you add country-specific resources, identify the geography clearly.

## Contributing process

1. Fork the repository.
2. Create a branch for your changes.
3. Add or update content.
4. Open a pull request with a short summary.
5. Reference any new resources with authoritative links.

## Style guide

- Use simple English.
- Prefer bullet lists, tables, and short paragraphs.
- Keep each resource entry concise.
- Do not create promotional or affiliate content.

## Issue guidelines

- Use issues for suggestions, corrections, or missing resource requests.
- For urgent updates, add a brief note and a link to the source.
