# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository, please open an issue and tag it as a security concern.

## What to include

- A clear description of the problem
- Steps to reproduce the issue
- Any example code or screenshots

## Response

The maintainer will review security reports promptly and provide a follow-up within a reasonable timeframe.

## Responsible Disclosure

Please do not publicly disclose vulnerabilities until they have been reviewed and fixed.
